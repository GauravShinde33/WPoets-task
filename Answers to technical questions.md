 3. How would you track down a performance issue in production? Have you ever had to do this?

First, I would check browser developer tools and network requests to find where the slowdown is happening.

Then I would:
- Check database queries
- Optimize large images or files
- Check server logs and errors
- Reduce unnecessary API or database calls

In my personal projects, I have faced slow loading issues due to images and query handling, and I fixed them by optimizing images and improving the query logic.
